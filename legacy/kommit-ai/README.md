# kommit-ai

This package has moved.

Use the current Kommit CLI package instead:

```bash
npx @kommit/cli@latest --client claude-code
```

Kommit connects AI coding tools to persistent project memory: specs, decisions, learnings, and context that carry across sessions.

## Current Package

The maintained package is [`@kommit/cli`](https://www.npmjs.com/package/@kommit/cli).

```bash
npx @kommit/cli@latest
```

## Legacy Compatibility

This legacy package remains available so users who find `kommit-ai` on npm get clear installation guidance. Its `kommit` binary forwards to `@kommit/cli@latest`.
